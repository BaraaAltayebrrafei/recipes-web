
# Recipes Web

A social recipe-sharing web app where users can post recipes, follow other cooks, and order dishes.

## Features
- User accounts: sign up, log in, profile pages
- Add, view and delete recipes
- Like, save and comment on recipes
- Follow / unfollow users, with notifications
- Cart, ordering and order history
- Admin view of all users

## Tech
PHP · MySQL · HTML · CSS · JavaScript 

## Run locally
1. Install XAMPP (or any PHP + MySQL server)
2. Import `create_database_with_data.sql` into MySQL
3. Set your database details in `connection.php`
4. Put the folder in `htdocs` and open `http://localhost/recipes-web`
